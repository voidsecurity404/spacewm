# spacewm "dust": a desert town in the style of classic two-site maps.

# The map is a grid of cells, carved out of solid walls by the commands below.
#   size COLS ROWS CELL_METRES WALL_HEIGHT
#   fill CHAR C0 R0 C1 R1          every cell from column C0..C1, row R0..R1 (inclusive)
#   stairs DIR C0 R0 C1 R1 A B      raised paving whose level goes from A to B along DIR
#                                   (x+ east, x- west, z+ south, z- north)
#   spawn C R YAW                   where you start (yaw 0 looks north, 90 east)
# Columns go west -> east, rows north -> south. Cell chars:
#   #  wall (the default)            .  sand          ,  paving
#   1-9 paving raised that many steps (0.35 m each: walkable stairs)
#   A  archway: open below, wall above the opening
#   T  tunnel: open below, a roof and the building above
#   c  crate   C  two crates stacked   w  low wall you can look over
#   d  door leaf across a north-south passage   D  door leaf across an east-west one
#   m  a painted metal box (a shut market stall)
