# Dust map assets

The map layout (`map.txt`) is made for spacewm. It is *inspired by* the feel of classic
desert maps (two bomb sites, a long corridor, a middle route, tunnels); it copies no
geometry, textures or names from any game.

All textures are from [Poly Haven](https://polyhaven.com), licensed **CC0** (public
domain: free to use, change and share, no credit required). Resized to 512x512 JPEG.
